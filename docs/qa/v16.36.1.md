# v16.36.1 手書き認識の復帰修正

認識待ちの手書きを含む状態で「取消」や復元を行うと、画面に「文字を認識中」が残る問題を修正しました。元の手書きデータを保持したまま、復元された記録の認識を再開します。

- 対象：取消、ゴミ箱からの復元、バックアップファイルの復元、他端末からの自動取込。
- 曲の「記録を写す」でも手書きを個別に保持し、元の記録を削除してもコピー先の認識を完了します。
- 遅れて到着した古い結果は無視し、手動で修正した文字は保持します。重複した再開処理は同じ認識を二重実行しません。

2026-09-22 の確認：

- 自動テスト63件成功。今回の5つの復帰経路の回帰テストを含みます。
- 独立したChromeと架空データを使用し、320×568、390×844、844×390の表示幅で4項目の配置、単押し保存、手書き保存、続けて次の指摘を入力する操作、文字修正、再読み込み後の原文・修正文保持を確認。
- アプリのキャッシュ作成後、オフラインでの起動・新規手書きの保存・端末内認識を確認。
- 実際の認識モデルの取得を保留し、「手書き保存→別の指摘→取消→取得再開」を実ブラウザーで検証。原文を保持して認識が完了しました。
- ブラウザーの未処理エラーなし。公開セットリストの変更なし。

これは画面幅を変えたChromeでの検証です。実iPhone/Safari、指・ペンでの書きやすさ、一般的な日本語の認識精度は未確認です。1マス1文字の認識は引き続き試用扱いとし、元の手書きと修正可能な文字を表示します。
