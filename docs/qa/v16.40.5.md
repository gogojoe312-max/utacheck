# v16.40.5 — Status-bar blur follow-up

The user reports that the upper caption remains blurred in the v16.40.4
installed-iPhone screenshot. The previous claim that it was resolved was wrong.
The 16px guard was insufficient on this device, and an opaque CSS pseudo-element
cannot undo a native effect composited above the entire web page.

Changes:

- Request Apple's opaque `black` status bar instead of `black-translucent`.
  Apple documents that opaque status bars place web content below the status bar.
- Account for existing Home Screen installations retaining their earlier mode:
  when the actual top inset indicates an overlay, reserve a 48px portrait guard.
  This moves the caption 32px below its previous position, into the vertical
  region where the title was readable in the supplied screenshot.
- Remove the ineffective pseudo-element. Apply no extra guard when iOS already
  reserves the status area, or in Safari, desktop, Android, or landscape.
- Keep the viewport-height correction and single bottom inset from v16.40.4.
  No reinstall or local-data migration is needed for the fallback layout.

Primary reference:
https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariHTMLRef/Articles/MetaTags.html

Validation: reuse viewport-mode, keyboard and member-summary tests; verify the
published metadata and styles. The available browser is desktop Chromium and
cannot verify iOS's native blur. The guard is a screenshot-informed mitigation,
not a real-device-tested guarantee or a way of disabling the compositor.
