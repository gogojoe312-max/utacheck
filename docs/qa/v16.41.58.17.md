# v16.41.58.17 — Common LIVE and REC settings interactions

REC folder rename now replaces the complete visible folder name. The current
name is prefilled in the same organization form used by LIVE, with immediate
editable focus, draft preservation and IME protection. The recording date stays
in the song metadata independently of its folder name.

REC uses the shared forms for folder creation and moving songs, and supports
safe folder deletion, empty folders, drag moves and restoring date order. Drops
onto a destination folder header or a song within it use the same destination.
Folder deletion moves songs to “フォルダなし” while retaining songs and recordings.
Folder ordering remains scoped to the selected group or artist. Both modes
remember folder expansion synchronously so immediate redraws cannot reopen a
folder the user just closed.

LIVE and REC use one song-name editing form. REC date and artist editing uses a
single draft sheet with the same Save and Close interaction. Mutations retain
verified backup checks, stale-state protection and Undo. Existing session IDs,
recording dates, lyrics, notes and audio are preserved by folder operations.
