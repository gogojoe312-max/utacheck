# v16.41.18 — Remember the last performance and group

Reopening now restores the last deliberately selected performance, its valid
import group, and the performance-list group filter, including All. The small
navigation preference is saved immediately on this device, separately from the
IndexedDB content snapshot and from published/backup data. Existing saved
selections are adopted on the first upgraded launch.

Cloud refreshes restore the local preference after receiving data, without
rewriting show/song ownership or scheduling publication. Missing selections
fall back to available content; the preference survives delayed data arrival.
A newer user choice replaces it immediately. Viewer preferences are isolated by
source, cannot select another group's unavailable performances, and do not affect
editor preferences or preview mode. Recording mode remains intact.

Validation:

- All 175 Node tests passed, including 14 new selection regressions
- Covered fresh-runtime reopening, immediate persistence, legacy migration,
  delayed cloud content, newer user choices, stale/deleted/hidden IDs, source
  isolation, preview/recording, malformed/full/blocked storage, cloud backup
  signature alignment, and unchanged routing/content
- Syntax checks and `git diff --check` passed
- Existing scope-check script requires the unavailable optional `acorn` package
- The browser regression suite is available as
  `tests/selection-navigation-browser.cjs`; results and execution limits below

Only synthetic data was used. No real member publication, source recordings,
lyrics, or user backups were read or written during verification.

Browser verification limitation: Chromium could not start because the execution
environment rejected its process-singleton socket (`Operation not permitted`).
The provided browser also blocked the local fixture URL. Consequently the new
mobile/reopen/profile-restart suite, existing member browser regression, and
screenshots were not run. Its syntax was checked. Native iPhone Safari and an
installed home-screen PWA were not available; those results are not claimed.
