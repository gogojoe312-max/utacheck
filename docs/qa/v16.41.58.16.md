# v16.41.58.16 — Folder input and drag ordering

Folder rename opens a writable text field and focuses it synchronously in the
opening tap. LIVE organization forms and REC date-folder rename keep their draft
through redraws and Japanese IME confirmation. Verified backups run on Save;
failed backups, concurrent edits, closed dialogs, and loss of writer ownership
cannot commit stale input.

LIVE and REC folder headers use the same drag interaction as setlist songs.
One-step up/down menu actions are removed. Folder order is saved per LIVE group
or REC artist filter. REC rename preserves the recording date and manual order.
Song reordering preserves the selected song and other groups' positions; REC
song dragging stays within its date/artist section. Pointer cancellation does
not save an order change.
