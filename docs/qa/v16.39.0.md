# v16.39.0 — メンバーの指摘と総括

- メンバー別を曲単位に統一。共通の総括を個人への指摘より先に表示。
- 指摘ゼロでも総括があれば表示。空の総括は省略。
- 名前を配信元ごと・端末ごとに記憶。受信でIDが変わっても名前で復元。
- 曲別にも総括のみの曲を表示。全公演で各曲の公演IDから総括を取得。
- 各曲から歌詞を開ける。メンバーの表記は「指摘」「公演」に統一。
- 鍵盤・ピッチ・メトロノームを練習ツールに折り畳み。
- 指摘画面と比較画面のヘッダーを共通化。総括取得も共通化。
- 上書きされ使われなくなった旧キーボード位置調整と重複イベント、重複状態キーを削除。

## 検証

Node回帰テスト77件。メンバー別の総括、指摘ゼロ、過去公演、別グループの除外、名前の再起動復元・ID更新・配信元分離、プレビュー時の記憶保護、保存不可時、歌詞への移動を含む。
