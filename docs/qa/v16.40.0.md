# v16.40.0 — 公演と配信先を連動

- 公演の既定グループ、名前・フォルダ、所属曲から配信先を判定。OCHAなど英語グループ名先頭の略称にも対応。
- 公演選択と取り込み先を連動。公演を再度押しても選択解除しない。
- 公演カードに現在の配信先を表示。「配信先」で例外を指定、「自動」で既定に戻せる。
- 配信データを公演の配信先で組み立て、曲・指摘・総括を一緒に送る。曲本来の所属は変更しない。
- グループの接続管理を折り畳み。配信しない公演と非表示公演は引き続き除外。
- 未確認数・確認一覧・仮チェック・手動の改善判定を廃止。対応モジュール、CSS、読み込み、イベントと旧機能のテストを削除。保存済みデータ自体は保持。
- 前回の指摘が今回なければ「直った」に分類。今回も指摘があれば継続扱い。
- メンバー画面の下部「指摘に戻る」を削除し、上部「戻る」に統一。
- 起動時に保存したメンバー名を復元。公演や配信側IDが更新されても同じ名前で開く。

検証：83件のNodeテスト成功。実際の配信データ生成を使用し、配信先分離、上書きと自動復帰、非公開除外、指摘ゼロ時の改善判定、別公演へのメンバー引き継ぎを確認。
iPhone実機の確認は未実施。
