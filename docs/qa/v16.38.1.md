# v16.38.1 — faster deletion and safe shorthand

Changes:
- Local note deletion targets increase from 26/30 to 44 CSS pixels. Long memo text can wrap beside the fixed-size delete target.
- Shorthand now stores existing tag IDs, including はや → fast (リズム速い), まい → mic (マイク), たか → pHi (音程高い), なが → long (長い). Full spellings, kanji and katakana also match. Multiple terms store distinct IDs in one note, so lyrics, summary, publication and exports use the same categories.
- Recognition feedback appears inside the existing context row without changing button positions. Known phrases save as tags without a duplicate memo. Free prose remains a memo. Matching generic category buttons are replaced by the typed specific tag.
- Only complete known terms and explicit lyric-position patterns expand. Free text such as あたたかい and negative instructions remain unchanged. Already written categories are not duplicated.
- An empty input takes priority over an older draft, including during background save.
- Detailed note buttons retain focus until click as the quick panel already does. Viewer mode cannot invoke note deletion.
- Immediate input focus and the existing visualViewport positioning remain in place.
